# Organizador de Horários de Estudos

## Descrição do projeto

O Organizador de Horários de Estudos será uma aplicação web desenvolvida para ajudar estudantes a organizar sua rotina de estudos de forma simples e prática.

A aplicação terá como objetivo permitir que os estudantes planejem seus horários, organizem as disciplinas que precisam estudar e acompanhem suas atividades acadêmicas.

## Objetivos

- Facilitar a organização da rotina de estudos.
- Permitir o planejamento de horários para cada disciplina.
- Ajudar os estudantes a manter uma rotina de estudos organizada.
- Contribuir para o gerenciamento do tempo dedicado às atividades escolares.

## Funcionalidades previstas

- Cadastrar disciplinas.
- Organizar horários de estudo por dia da semana.
- Registrar tarefas e atividades escolares.
- Consultar o planejamento semanal de estudos.

## Tecnologias utilizadas

- Python
- FastAPI
- HTML e CSS (previstos para a interface web)
- Pytest para testes automatizados
- Ruff para verificação e formatação do código
